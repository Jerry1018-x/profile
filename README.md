# 个人网站

纯 HTML、CSS 和 JavaScript 网站，无需安装依赖或构建。

- `index.html`：个人主页
- `questionnaire.html`：资料问卷，登录、上传和保存依赖原 WorkBuddy 云服务
- `assets/`：图片及图标

## 部署
